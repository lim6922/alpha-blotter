# Alpha Blotter

개인 트레이딩 기록을 관리하기 위한  
**브라우저 기반 블로터(Blotter) 도구**입니다.

이 프로젝트는 **UI/로직 코드 전용(Public)** 저장소이며,  
실제 개인 트레이딩 데이터는 포함하지 않습니다.

## 🔒 개인 데이터 관리 방식 (중요)

- 실제 트레이딩 데이터는 **별도의 Private 저장소/Supabase**에서 관리합니다.
- 이 Public 저장소에는 **실제 데이터(CSV)가 포함되지 않습니다.**
- 데이터 반영 경로는 아래 2가지를 지원합니다.
  - CSV Import / Export
  - 클라우드 동기화(로그인 기반)

---

## ☁️ 클라우드 동기화 (로그인 기반)

헤더의 아래 버튼을 사용합니다.
- `동기화 로그인`
- `동기화 가져오기`
- `동기화 내보내기`

### 자동 동작(현재 기준)

- 로그인 세션이 확인되면 **동기화 가져오기(auto import)** 를 자동으로 1회 시도합니다.
- 자동 가져오기 이후, 로컬 변경이 `sync-bar` 기준 `WARN` 상태가 되면 **자동 내보내기(autosync export)** 를 시도합니다.
- 자동 동기화는 사용자 허용 이메일(allowed_emails) 검증을 통과한 계정에서만 동작합니다.

### 수동 동작

- `동기화 가져오기`: 원격 데이터로 로컬을 덮어씁니다.
- `동기화 내보내기`: 현재 로컬 데이터를 원격에 저장합니다.

---

## 📥 CSV 데이터 불러오기 (Import)

1. 앱 실행 (위 GitHub Pages 주소)
2. **CSV 가져오기 버튼 클릭**
3. 개인 트레이딩 데이터 CSV 파일 선택
   - 예: `blotter.csv`
4. 데이터가 화면에 로드됩니다

👉 CSV 파일은 **개인 Private 저장소에서 다운로드**합니다.

---

## 📤 CSV 데이터 저장하기 (Export)

1. 앱에서 거래 기록 입력 / 수정
2. **CSV 내보내기 버튼 클릭**
3. CSV 파일 저장
4. 개인 데이터 저장소에 덮어쓰기 후 커밋

👉 CSV 백업/버전 관리는 **Private 저장소에서 Git으로 관리**합니다.

---

## ⚠️ 주의 사항

- 이 저장소는 **데모/실행용 UI**입니다.
- 개인 금융 데이터, 실계좌 정보는 업로드하지 마세요.
- 실데이터는 반드시 **Private 저장소 또는 본인 Supabase 프로젝트**에서만 관리하세요.
